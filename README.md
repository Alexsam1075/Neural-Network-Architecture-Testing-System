# Neural Architecture Testing System

Это очень крутая технология на ранней стадии разработки, которая кажется мне очень перспективной!

## Что здесь особенного?

В интернете все тестируют готовые AI модели (GPT, Claude и т.д.). Я же делаю что-то другое - **тестирую саму архитектуру**, а не обученный вес.

Вопросы, которые я изучаю:

- Насколько архитектура устойчива к шуму?
- Как она справляется с супер длинными контекстами (1М+ токенов)?
- Может ли обрабатывать сложные паттерны без обучения?
- Как архитектура адаптируется к новым данным в реальном времени?

**Я ещё такого не видел в интернете.** Это уникальный подход к анализу нейросетевых архитектур.

## Что есть в проекте

- **Много архитектур**: Transformer, SSM, AION (собственная разработка) и другие
- **Anti-cheat система**: архитектуры не могут "жульничать" через кэширование
- **Экстремальные тесты**: работа с шумом, длинные контексты, сложные паттерны
- **Умное кэширование**: быстрое повторное тестирование
- **Поддержка GPU**: CUDA для ускорения

## Быстрый старт

```bash
# Установка
pip install -r requirements.txt

# Запуск тестирования
python start_test.py

# Результаты в results/test_results_v3.json
```

## Параметры запуска

```bash
python start_test.py --only-new           # Только новые архитектуры
python start_test.py --architectures Transformer SSM  # Конкретные архитектуры
python start_test.py --tests NumberSequenceTest       # Конкретные тесты
# стандартный таймаут 60 секунд что бы изменить используйте флаг --timeout <ваше количество секунд>
```

## Структура

```
├── Architectures/    # реализация архитектур
├── Tests/            # Модули тестирования
├── helper/           # Вспомогательные функции
├── results/          # Результаты тестирования
├── start_test.py     # Главный скрипт
└── config.json       # Конфигурация
```

## Типы тестов

- **NumberSequenceTest** - числовые последовательности и паттерны
- **NextTokenTest** - предсказание следующего токена
- **UltraLongContextTest** - контексты от 100K до 1M+ токенов
- **GenerationQualityTest** - качество текстовой генерации
- **AntiCheatTest** - честность результатов
